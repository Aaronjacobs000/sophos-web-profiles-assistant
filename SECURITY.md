# Security

## Reporting a vulnerability

Report it privately: on the repository's Security tab, choose [Report a vulnerability](https://github.com/Aaronjacobs000/sophos-web-profiles-assistant/security/advisories/new). Please don't open a public issue.

## In scope

- The local server and its API
- How the tool handles credentials and the data it keeps
- The pages and the reports
- Rollback and snapshots

## Sophos products

This is an unofficial community tool, not a Sophos product. Report issues in Sophos products, Sophos Fusion included, to Sophos.
